# Pallet Loading Optimizer — Implementation Handoff

This folder is the implementation-ready handoff for a SaaS application that optimizes non-stackable pallet and freight placement in road vehicles.

Start with `tasks/TODO.md`. The first task is the orchestrator task. It must coordinate all subsequent tasks, keep documentation and task files synchronized, and never advance while the current task acceptance criteria are not met.

The session is reconstructed from the design interview in the source conversation. Locked decisions are separated from unresolved matters.
