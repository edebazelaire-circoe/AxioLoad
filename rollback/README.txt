Points de restauration inclus
=============================

- AxioLoad_0.4.0_original.zip
  Version complète immédiatement antérieure à cette évolution d’interface.
  Utiliser ce fichier pour revenir à la version 0.4.0 sans les paramètres, le mode sombre et les aides contextuelles.

- pallet_loading_optimizer_v3_original.zip
  Point de restauration historique antérieur à l’intégration de l’identité AxioLoad.

Ne pas supprimer le volume Docker lors d’un retour arrière. Utiliser `docker compose down` sans l’option `-v`.
